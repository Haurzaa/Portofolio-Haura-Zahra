# Haura Zahra — Portfolio

Website portfolio satu halaman yang dibuat berdasarkan CV Haura Zahra.

## Isi
- Home
- About
- Experience
- Skills
- Education
- Contact

## Cara menjalankan
1. Ekstrak folder/ZIP.
2. Buka `index.html` di browser.
3. Tidak membutuhkan server untuk tampilan dasar.

## Kustomisasi
- Edit teks di `index.html`.
- Edit warna, ukuran, dan layout di `style.css`.
- Edit interaksi/animasi di `script.js`.
